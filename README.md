# UrbanMart Sales Analysis Report
This project showcases a full-cycle data analytics workflow, from data preprocessing to visualization, using SQL and Power BI. The goal was to analyze UrbanMart’s transaction data to extract meaningful insights for strategic business decisions.

## Project Overview
UrbanMart, a retail chain, provided a dataset of 50,000 transactions. The analysis focuses on sales performance, customer demographics, and payment method preferences. SQL was used to process and transform the raw data, and Power BI was utilized to create an interactive dashboard for visualization and insights.

## Key Objectives

**1.Data Preparation and Cleaning**
- The dataset was loaded and cleaned using SQL to ensure data consistency and accuracy.
Performed operations such as filtering, grouping, aggregating, and joining to prepare data for analysis.

**2.Data Analysis**
- Analyzed sales performance across different product categories and regions.
Studied customer demographics, including age group and gender, to identify patterns in purchase behavior.
Explored payment trends to determine popular payment methods.

**3.Visualization and Insights**
- Designed an interactive Power BI dashboard for visual storytelling.
Empowered users to drill through data and apply filters for a detailed exploration of metrics.

## Dataset Details
**The dataset contains the following attributes:**
- **TransactionID:** A unique identifier for each transaction.
- **CustomerID:** Unique identifiers for customers.
- **TransactionDate:** The date of the transaction.
- **TransactionValue:** The total value of each transaction.
- **ProductCategory:** Categories of purchased products (e.g., Fashion, Beauty, Sport).
- **PaymentMethod:** Payment methods used (e.g., Credit Card, Bank Transfer).
- **CustomerGender:** Gender of the customer (Male/Female).
- **CustomerAgeGroup:** Customer age brackets (e.g., 18-25, 26-35).
- **Region:** Geographic region where the transaction occurred (e.g., Jakarta, Surabaya).

## Technical Workflow
**1. Data Preprocessing (SQL)**
- **Cleaning:** Removed duplicates and ensured data consistency.
- **Transformations:** Calculated aggregated metrics like total revenue, average transaction value, and category-specific insights.
- **Queries:** Wrote SQL scripts for trend analysis, segmentation, and ranking of top-performing regions and categories.
